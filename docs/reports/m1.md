# Milestone M1 report: foundation

Date: 2026-11-06. Scope per `docs/SPEC.md` section 17: backend, auth, SPA shell, chat with
streaming, model configuration, cost, tracing. Tests assigned to M1: P6-A01 to A04, A17 and part
of A22.

## What was built

Backend (`src/rampart`, Python 3.12, FastAPI, SQLAlchemy on SQLite in WAL mode, LangGraph):

- `auth`: Argon2 password hashes, admin-created accounts, roles `user` and `admin`, httpOnly
  session cookie whose database key is a hash of the token, CSRF token checked on every
  state-changing request, password change that signs other sessions out.
- `catalog`: `models.yaml` parser with validation, provider availability probe (OpenRouter key
  present; Ollama reachable and model pulled), Slot resolution with admin overrides stored in the
  database, per-Slot temperature and max tokens, enable/disable per Model with a guard against
  disabling a Model a Slot uses.
- `chat`: LangGraph graph (`load_context`, stub `input_guard`, `generate`) with a SQLite
  checkpointer per Conversation; a turn engine that streams text deltas and returns the final
  message; a service that mirrors messages for the UI, streams server-sent events
  (`start`, `delta`, `usage`, `done` or `error`), persists partial output on disconnect, and
  refuses a second concurrent turn on one Conversation.
- Cost: `OpenRouterChat`, a small `ChatOpenAI` subclass. When streaming, `langchain-openai`
  reduces the final usage object to token counts and drops OpenRouter's `cost` field; the
  subclass copies the raw usage object into the chunk metadata so the figure survives. A fallback
  asks OpenRouter's generation endpoint when a streamed response carried no cost. Ollama turns
  cost zero. No pricing table exists (ADR 0002).
- `tracing`: one trace per turn; Langfuse through the LangChain callback handler with user id,
  Conversation id and model propagated, or JSONL files under `data/traces/` without keys. The
  trace id is stored on the assistant message.
- `usage`: totals per user and per Model, and per user for admins.
- CLI `rampart`: `init`, `serve`, `user create|reset-password|list`, `demo` (accounts only in M1).
- Static serving of `frontend/dist` with a client-route fallback that cannot leave the build
  directory; `/api/docs` for the interactive reference.

Frontend (`frontend/`, React 19, Vite 8, TypeScript 6, Tailwind 4, shadcn/ui, React Router 8,
TanStack Query 5): login, app shell with Conversation list (rename, delete), streaming chat with
Markdown rendering (no raw HTML, images never fetched), model picker, per-message model, token,
cost and latency line, error state, stop button, account page (password, own usage), admin page
(users, Models and Slots, usage for everyone), dark mode, phone layout. Built by a delegated agent
against `docs/API.md`; its browser-level check (mocked API, screenshots, 390 px width) found and
fixed two layout defects.

## Decisions made during the build

- Persistence of the mirrored messages happens in the chat service around the graph, not in a
  graph node; the graph keeps only the model-facing history.
- A Slot override row carries the full value set (model, temperature, max tokens) copied from
  the file defaults on first change; resetting deletes the row.
- Usage totals count every assistant message, including failed turns (cost null, shown as zero),
  so they match the Conversation message counts.
- Ollama catalog entries carry an `ollama/` prefix so ids never collide with OpenRouter ids.
- The `live` pytest marker holds tests that need real providers; they are excluded by default.
